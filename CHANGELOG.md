# Urbique — Changelog

Author: Chand Parvani <chandparvani93@gmail.com>

- Initial release of the Urbique block theme.
- Added full-site-editing templates and template parts.
- Added seven reusable block patterns.
- Added After Hours and Quiet Minimal style variations.
- Added theme documentation and GPL licensing information.
