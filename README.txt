An editorial full-site-editing theme for architecture, interior design, and creative portfolios.

== Description ==

Urbique is a WordPress block theme for architecture practices, interior designers, and creative studios. Its layouts combine expressive typography, generous spacing, and a restrained colour palette. Templates, template parts, and patterns can be edited in the WordPress Site Editor.

The theme is built with WordPress core blocks and does not require a companion plugin.

== Features ==

* Full Site Editing support.
* Global design settings and styles managed with theme.json.
* Editable header and footer template parts.
* Front page, page, single, archive, search, index, home, and 404 templates.
* Seven reusable block patterns for common studio website sections.
* After Hours and Quiet Minimal style variations.
* Responsive layouts and reduced-motion support.
* Translation-ready strings and text domain.

== Installation ==

1. Upload the urbique folder to /wp-content/themes/, or upload the ZIP from Appearance > Themes > Add New > Upload Theme.
2. Activate Urbique.
3. Open Appearance > Editor to customize templates, template parts, patterns, and styles.
4. Set a static homepage under Settings > Reading to use the front-page template as the site homepage.

== Customization ==

* Set your Site Title and Site Logo in the Site Editor.
* Edit the header navigation and footer contact information.
* Add posts with featured images and categories to populate the portfolio and journal queries.
* Update the contact email address in the front-page template, footer, and Contact pattern if your public contact details change.
* Insert and customize the included patterns from the block inserter.
* Select After Hours or Quiet Minimal from Styles in the Site Editor.
